# IEEE Conference Report

`main.tex` and `references.bib` are an Overleaf-ready IEEE conference
manuscript. Upload the contents of this folder to an Overleaf project using
the IEEE Conference template, then compile `main.tex`.

The manuscript reports only the real-run artifacts under `results/`. Task 1
is explicitly identified as a MusicCaps caption-to-tag proxy experiment; the
FMA-small Task 2 and Task 3 results are reported separately. The remaining
plots and exported case studies can be added to the supplementary material
or used while expanding the qualitative-analysis section.
