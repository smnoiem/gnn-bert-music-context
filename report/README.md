# Report checklist

Use this folder for the 6--10 page NeurIPS/IEEE/ICML-style report after real training runs. Include: dataset and artist-disjoint split protocol; audio graph construction; Tasks 1--3 architecture; macro/micro F1 and mean PR-AUC; the four-condition ablation; CNN/majority baselines; t-SNE; and three exported case studies. Do not include synthetic smoke-test metrics as experimental results.
